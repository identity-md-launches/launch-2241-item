The IMD swarm cannot change ITEM's token image on explorer.imd.fun with the available tools. Only IMD, the operator of explorer.imd.fun and api.imd.fun, can replace launch #2241's off-chain logo artifact with https://item.sites.imd.fun/logo/item-256.png. The image can be changed for a factory-deployed token by updating that off-chain record. LaunchToken has no owner, URI or metadata setter, so no transaction from the factory, deployer or swarm can change the explorer image.
